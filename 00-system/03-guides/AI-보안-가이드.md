# grandeclip AI 활용 보안 가이드

> **대상**: 전 임직원
> **목적**: 전사 AI Transformation(AX) 추진 시 반드시 지켜야 할 보안 원칙
> **문의**: #gc-ai-라운지
> **최종 업데이트**: 2026년 4월

---

## 왜 이 가이드가 필요한가요?

우리 회사는 전사적으로 AI Transformation(AX)을 추진하고 있습니다. ChatGPT, Claude, Gemini 등 생성형 AI 도구를 업무에 적극 활용하는 것은 환영하지만, **보안 사고의 대부분은 기술이 아니라 사람의 부주의에서 시작됩니다.**

2026년 CSA(Cloud Security Alliance) 조사에 따르면 **직원의 29%가 회사 미승인 AI 도구를 업무에 사용**하고 있으며, **보안 리더의 92%가 AI 에이전트의 보안 위협을 우려**하고 있습니다. KISA(한국인터넷진흥원) 역시 임직원의 부주의로 인한 AI 관련 보안 사고가 빈번히 발생한다고 경고합니다.

이 가이드는 모두가 **쉽게 이해하고 바로 실천할 수 있도록** 작성되었습니다.

## 한눈에 보는 요약표

| 영역 | ✅ DO | 🚫 DON'T |
| --- | --- | --- |
| **데이터 입력** | 공개 가능 정보만 입력, 민감 정보 익명화 | 개인정보, 기밀, 비밀번호 입력 금지 |
| **도구 사용** | 계정 분리, 학습 Opt-out, 새 도구는 정책 확인 | 출처 불분명 도구·확장 임의 설치 금지 |
| **결과물 활용** | 반드시 사람이 검증, 사실 확인 후 공유 | 검증 없이 외부 공유 금지 |
| **파일 관리** | 보안 등급 확인, 사내 환경 활용 | 내부 문서 외부 AI 업로드 금지 |
| **에이전트/자동화** | 최소 권한, 로그 확인 | 무분별한 권한 부여 금지 |
| **사고 대응** | 즉시 신고(#gc-ai-라운지), 보안 교육 참여 | 사고 은폐 금지, 의심 링크 클릭 금지 |

> **💬 Shadow AI란?**
> 회사가 파악하지 못한 채 직원이 개인적으로 쓰는 AI 도구·기능을 뜻합니다.
> **예시**
> - 검증 안 된 크롬 확장 "AI 요약기" 설치 후 내부 링크 요약
> - 출처 불분명한 무료 도구에 데이터 연동
>
> Shadow AI는 의도가 좋아도 **회사가 사고 발생 시 파악·대응할 수 없다**는 점에서 가장 큰 리스크입니다.

## 1. 데이터 입력 — 무엇을 넣어도 되고, 안 되는가

### ✅ DO (이렇게 하세요)

- **공개 가능한 정보만 AI에 입력하세요.** 뉴스 기사 요약, 일반적인 업무 질문, 공개된 시장 정보 등은 자유롭게 활용 가능합니다.
- **민감 정보는 반드시 익명화/가명화 후 입력하세요.** 예: 고객명 → "고객 A", 매출액 → "약 XX억 수준"
- **입력 전 스스로 질문하세요:** *"이 내용이 내일 뉴스에 나가도 괜찮은가?"* 답이 No라면 입력하지 마세요.

### 🚫 DON'T (절대 하지 마세요)

- **고객 개인정보(이름, 연락처, 주민번호, 의료정보 등)를 AI에 입력하지 마세요.**
- **재무 데이터, 미공개 실적, 투자 계획 등 내부 기밀을 입력하지 마세요.**
- **계약서, 법률 문서, NDA 내용을 그대로 붙여넣지 마세요.**
- **소스코드, API 키, 비밀번호, 인증 토큰을 절대 입력하지 마세요.**
- **직원 인사 정보(급여, 평가, 징계 기록 등)를 입력하지 마세요.**

> 💡 **기억하세요**: 외부 AI 서비스에 입력한 데이터는 **학습 데이터로 사용될 수 있고**, 제3자에게 노출될 위험이 있습니다.

## 2. AI 도구 사용 — 어떤 도구를, 어떻게 써야 하는가

> 💬 **참고**: 현재 우리 회사는 특정 AI 도구를 지정하여 사용/금지하는 별도 가이드가 없습니다. 즉, **어떤 AI 도구든 자유롭게 탐색하고 활용할 수 있지만**, 그만큼 아래 보안 원칙을 각자가 더 철저히 지켜야 합니다.

### ✅ DO (이렇게 하세요)

- **새로운 AI 도구를 사용하기 전, 해당 서비스의 데이터 처리 정책(약관)을 직접 확인하세요.** 특정 승인 목록이 없는 만큼 각자의 판단이 중요합니다.
- **업무용 계정과 개인 계정을 반드시 분리하세요.** 개인 ChatGPT/Claude 계정으로 업무 데이터를 처리하지 마세요.
- **AI 도구의 데이터 공유/학습 설정을 반드시 확인하세요.** 대부분의 AI 도구에는 "대화 내용을 학습에 사용" 옵션이 있습니다 → **반드시 비활성화(Opt-out)** 하세요.
- **유료 엔터프라이즈/비즈니스 플랜을 우선 사용하세요.** 유료 플랜은 일반적으로 데이터를 학습에 사용하지 않고, 보안 수준이 더 높습니다.
- **새로 발견한 유용한 AI 도구가 있다면 #gc-ai-라운지에 공유하세요.** 향후 전사 표준 도구 선정에 참고할 수 있습니다.

### 🚫 DON'T (절대 하지 마세요)

- **데이터 처리 정책을 확인하지 않은 채 낯선 AI 도구에 업무 데이터를 입력하지 마세요.**
- **출처가 불분명한 AI 도구, 브라우저 확장 프로그램을 임의로 설치하지 마세요.** (Shadow AI 위험)
- **무료/체험판 AI 서비스에 업무 자료를 업로드하지 마세요.** 무료 서비스일수록 데이터 활용 범위가 넓습니다.
- **"다른 팀도 쓰니까 괜찮겠지"라고 판단하지 마세요.** 전사 승인 도구가 없는 현재 상황에서는 각자가 보안 판단의 주체입니다.

## 3. AI 결과물 활용 — 믿되, 검증하라

### ✅ DO (이렇게 하세요)

- **AI가 생성한 모든 결과물은 반드시 사람이 검토하세요.** AI는 그럴듯하지만 틀린 정보(Hallucination)를 만들 수 있습니다.
- **AI 결과물을 외부에 공유할 때는 사실 확인을 거치세요.** 특히 숫자, 법률 조항, 인용문은 반드시 원본을 대조하세요.
- **AI로 생성한 콘텐츠에는 내부 기준에 따라 AI 활용 사실을 표기하세요.**

### 🚫 DON'T (절대 하지 마세요)

- **AI 결과물을 검증 없이 그대로 고객 대면 자료에 사용하지 마세요.**
- **AI가 생성한 법률/재무/의료 조언을 전문가 확인 없이 의사결정에 사용하지 마세요.**
- **AI 결과물에 포함될 수 있는 타사 저작권 침해 콘텐츠를 그대로 사용하지 마세요.**

---

## 4. 파일 및 문서 관리 — 올리기 전에 한 번 더 생각하세요

### ✅ DO (이렇게 하세요)

- **파일을 AI에 업로드하기 전, 해당 파일의 보안 등급을 확인하세요.**
- **대량의 데이터를 분석할 때는 사내 승인된 AI 환경(온프레미스, 엔터프라이즈 플랜)을 이용하세요.**
- **AI 작업이 끝난 후 대화 내역을 정리(삭제)하세요.** 불필요한 데이터 잔존을 방지합니다.

### 🚫 DON'T (절대 하지 마세요)

- **사내 문서(전략 보고서, 인사 자료, 재무제표)를 외부 AI에 업로드하지 마세요.**
- **고객으로부터 받은 자료를 허락 없이 AI 도구에 입력하지 마세요.**
- **AI와의 대화 내역을 캡처하여 외부 SNS나 커뮤니티에 공유하지 마세요.**

---

## 5. AI 에이전트 및 자동화 — 자동이라도 책임은 사람에게

### ✅ DO (이렇게 하세요)

- **자동화된 AI 작업에도 접근 권한을 최소한으로 설정하세요.** (최소 권한 원칙)
- **AI 에이전트의 동작 로그를 주기적으로 확인하세요.**
- **에이전트/자동화 설정 관련 궁금한 점은 #gc-ai-라운지에 공유하세요.**

### 🚫 DON'T (절대 하지 마세요)

- **AI 에이전트에 관리자 권한이나 전체 시스템 접근 권한을 부여하지 마세요.**
- **AI 자동화 결과를 사람의 확인 없이 바로 실행(이메일 발송, 데이터 수정 등)하도록 설정하지 마세요.**
- **AI 에이전트가 접근하는 데이터 범위를 파악하지 않은 채 운영하지 마세요.**

## 6. 보안 사고 대응 — 의심되면 즉시 신고

### ✅ DO (이렇게 하세요)

- **AI를 통해 민감 정보가 유출된 것이 의심되면 즉시 #gc-ai-라운지에 신고하세요.**
- **AI 도구에서 비정상적인 동작(이상한 응답, 예상 외 데이터 노출 등)을 발견하면 보고하세요.**

### 🚫 DON'T (절대 하지 마세요)

- **실수로 민감 정보를 입력했을 때 "별일 아니겠지"라며 넘기지 마세요.** 즉시 보고가 피해를 최소화합니다.
- **보안 사고를 숨기거나 개인적으로 해결하려 하지 마세요.**
- **AI 관련 피싱 메일이나 의심스러운 링크를 클릭하지 마세요.** AI를 사칭한 공격이 증가하고 있습니다.

## 이 워크스페이스의 보안 인지 기능

이 grandeclip 워크스페이스는 Claude Code 세션 안에서 위 원칙을 **거들어주는** 장치를 갖추고 있습니다.

- **보안 원칙 상시 인지**: 루트 `CLAUDE.md`에 보안 원칙이 담겨 있어, Claude가 매 대화에서 이를 인지합니다. (OS 무관 — Windows/mac/Linux 모두 동일)
- **민감정보 능동 감지**: 사용자 입력에 API 키·비밀번호·개인키·주민번호 형식 등이 보이면, Claude가 **작업을 막지 않고 경고 + 안전한 대안**을 먼저 제시합니다.
- **(선택) 결정적 스캐너 훅**: 정규식 기반의 확정적 경고가 필요한 팀은 `.claude/hooks/README.md`를 참고해 opt-in 할 수 있습니다. (기본 비활성 — OS별 인터프리터 제약 때문)

> ⚠️ **한계**: 이 기능은 **Claude Code 세션 내부**에서만 동작합니다. ChatGPT 웹 등 다른 도구에 직접 붙여넣는 행위까지 막지는 못합니다. 결국 가장 중요한 방어선은 **이 가이드를 이해한 여러분 자신**입니다.
