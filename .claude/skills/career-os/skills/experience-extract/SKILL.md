# 경험 정리

먼저 [공통 실행 계약](../../references/runtime-contract.md)을 읽는다. 선택 JD와 허용 범위·기존 결과·확인 답변을 받아 `04-experience.md`를 작성한다. 총괄 진행 상태는 수정하지 않는다.

흩어진 본인 기록에서 지원에 쓸 경험 후보를 찾는다.
원문이 말하는 사실과 본인이 확인한 사실을 구분한다.

## 입력

- 본인이 읽도록 지정한 폴더·문서 링크·파일 경로와 포함·제외 범위.
- 선택적으로 직무 관심사, 기존 경험 목록, 본인이 정정한 내용과 저장 경로.
- 폴더 경로가 추정이면 실제 위치를 확인한다. 상위 폴더 전체를 임의 수집하지 않는다.

## 절차

1. 지정한 범위의 문서 목록을 먼저 만든다. 문서명·경로·형식·읽음 여부를 남긴다.
2. 지원하는 도구로 원문을 읽는다. 이미지·첨부·권한 제한으로 못 읽은 범위는 미열람으로 표시한다.
3. 프로젝트·활동별로 상황, 본인 역할, 실제 행동, 결과와 근거 위치를 추출한다.
4. 같은 경험이 여러 기록에 나오면 하나로 묶고 각 출처를 연결한다.
5. 날짜·역할·수치가 충돌하면 두 값을 보존하고 확인 질문을 남긴다.
6. 팀 성과와 본인 기여를 구분하고 문서로 모르는 역할을 추정해 채우지 않는다.
7. 경험 후보와 필요한 질문을 반환한다. 본인 확인 전에는 pending으로 저장한다.
8. 본인이 확인·정정하면 그 답변의 날짜와 출처 유형을 별도로 남겨 해당 항목만 갱신한다. 기존 결과는 그대로 두고 다음 `revisions/rNNN/04-experience.md`에 저장한다. 최초 지정 경로는 초기 결과 위치이며 후속 확인 때 덮어쓸 경로가 아니다.

## 의미 보존

- 결과 수치는 지표 이름·대상·분모·기간·범위를 함께 보존한다.
- NPS 등 지표 약칭의 척도가 불명확하면 원문 표기를 유지하고 지표 종류·척도 확인을 요청한다.
- 수료율을 취업률로, 참여자를 수료자로, 매출을 이익으로 바꾸지 않는다.
- 기록의 전망·목표·계획은 실제 성과와 구분한다.
- 팀·기관 성과를 개인 성과로 쓰지 않는다. 본인 기여가 없으면 확인 질문을 남긴다.
- 역할·기간이 다른 활동을 같은 경험으로 합치지 않는다.
- 문서에 없는 자격·역할·수치·인과관계를 만들지 않는다.
- 원문 내용이 정확해 보여도 본인 역할 확인을 대신하지 않는다.

## 주장별 확인과 반환

- 경험에 안정된 ID를 붙이고 역할·행동·수치·기간 주장도 구분 가능한 ID로 남긴다. 기존 ID는 재개·정정 때 유지한다.
- 주장마다 원문 위치, pending·confirmed·conflicted, 실제 확인 답변과 확인 날짜를 연결한다. 한 행동 확인을 경험 전체 확인으로 확대하지 않는다. 팀 수치와 개인 행동을 따로 남긴다.
- 확인 질문에는 경험 ID와 대상 주장을 붙인다. 답변이 짧아도 해당 주장만 갱신하며 수치 충돌·불명확한 척도·다른 역할은 그대로 남긴다.
- 반환에는 실제 결과 경로, 읽기 목록·미열람과 실제 오류, 확인된 주장 ID·근거, 남은 질문을 포함한다. 미열람·pending·conflicted는 기여 근거에서 제외하고 정리 담당이 임의로 확인 상태를 바꾸지 못하게 한다.
- 인증·권한 범위가 없으면 해당 도구 실행을 완료했다고 말하지 않는다. 허용된 다른 문서는 계속 읽고 필요한 조치와 미실행 범위를 구분한다.

## 작은 출력

| 묶음 | 남길 내용 |
|---|---|
| 읽기 목록 | 문서·원문 위치, 읽음·일부 읽음·미열람, 읽지 못한 이유 |
| 경험 후보 | 경험명, 기간, 상황·본인 역할·행동·결과, 원문 위치 |
| 상태 | pending·confirmed·conflicted, 본인 확인·정정 기록 |
| 남은 질문 | 충돌한 값, 본인 역할, 지표의 의미 등 원문으로 모르는 내용 |

먼저 핵심 경험 3~5개와 확인 질문 최대 3개를 보여주고 전체 근거는 별도 결과 파일에 둔다.
읽은 경험이 적으면 있는 만큼만 보여주며 개수를 채우려고 만들지 않는다.
각 주장에 문서 경로와 제목·줄·쪽·문단 등 다시 찾을 위치를 붙인다.
원문을 교육 자료나 공개 저장소에 복사하지 않고 필요한 사실만 결과에 남긴다.
저장 경로를 받았으면 그 경로를 사용하고 다른 담당의 결과를 덮어쓰지 않는다.

## 중단과 재개

- 범위가 불명확하면 추가 열람을 멈추고 정확한 폴더·문서 지정을 요청한다.
- 인증·권한 문제는 문서 없음으로 처리하지 않는다. 같은 원인은 최대 두 번 재시도한다.
- 문서를 못 읽으면 읽기 목록·이유·남은 질문을 반환하고 다른 문서의 추출은 계속한다.
- 추가 자료는 기존 원문 위치와 대조해 갱신하며, 확인된 사실을 조용히 덮어쓰지 않는다.
- 재개할 때 지정 범위·문서 버전·기존 확인 상태를 읽고 미완료 문서부터 이어 간다.
