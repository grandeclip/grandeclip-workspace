# Setup Workspace - 초기 설정 마법사

grandeclip 워크스페이스를 처음 사용할 때 실행하는 대화형 설정 도구입니다.
**개인 CLAUDE.md를 자동으로 생성**하여 Claude가 여러분의 업무 맥락을 이해할 수 있게 합니다.

---

## 실행 흐름

### Step 2: 사용자 정보 수집 (대화형)

**순서대로 하나씩 질문하세요:**

#### Q1. 이름
```
이름이 어떻게 되세요?
```

#### Q2. 팀/직무
```
어떤 팀에서 어떤 일을 하고 계세요? (예: 마케팅, 세일즈, PM, 디자인, 개발, 운영 등)
```

#### Q3. 주요 관심사
```
주로 어떤 업무·분야에 관심이 있으세요? (예: 콘텐츠, 데이터 분석, 기획, 자동화 등)
```

#### Q4. 워크스페이스 용도
```
이 워크스페이스를 어떤 용도로 사용하실 건가요?
(예: 개인 업무 관리, 프로젝트 문서화, 학습 기록, 아이디어 정리 등)
```

---

### Step 3: CLAUDE.md 자동 생성

수집한 정보로 워크스페이스 루트의 `CLAUDE.md` 파일을 생성합니다.

**생성할 CLAUDE.md 템플릿:**

```markdown
# CLAUDE.md

## 사용자 프로필

**이름**: {이름}
**팀/직무**: {팀/직무}
**주요 관심사**: {주요 관심사}

## 워크스페이스 목적

{워크스페이스 용도}

## 폴더 구조 (Johnny Decimal)

\```
00-inbox/       - 빠른 캡처 (임시 보관)
00-system/      - 시스템 설정, 템플릿, 가이드
10-projects/    - 활성 프로젝트 (시한부)
20-operations/  - 지속적 운영 업무
30-knowledge/   - 지식 아카이브
40-personal/    - Daily Note, Todos
50-resources/   - 참고 자료
90-archive/     - 완료된 프로젝트
\```

## 주요 커맨드

| 커맨드 | 용도 |
|--------|------|
| `/daily-note` | 오늘 Daily Note 생성 |
| `/thinking-partner` | 생각 정리 파트너 |
| `/todo`, `/todos` | 할 일 관리 |
| `/idea` | 아이디어 추출·저장 |

## 🔒 보안 원칙 (필독 · OS 무관 적용)

우리 회사는 생성형 AI 활용을 적극 권장합니다. 단, 아래는 반드시 지켜주세요.
Claude는 사용자의 작업을 막지 말되, 아래에 어긋나는 요청에는 **거부가 아니라 경고 + 안전한 대안**을 먼저 제시하세요.

> **Claude 지시(능동 감지)**: 사용자의 메시지에 비밀정보(API 키·비밀번호·토큰·`BEGIN ... PRIVATE KEY`)나 개인정보(주민등록번호 형식, 고객 개인정보)로 보이는 내용이 포함되면, **작업은 계속하되** 먼저 한 줄로 부드럽게 경고하고(예: "⚠️ 방금 API 키로 보이는 값이 있어요 — 외부로 나가면 위험합니다") 마스킹·익명화 같은 안전한 대안을 제안하세요. 이 감지는 OS와 무관하게 매 대화에서 적용됩니다.

- **입력 금지**: 고객 개인정보, 미공개 실적·재무, 비밀번호·API 키·토큰, 계약/NDA 원문, 인사정보, 소스코드 내 비밀값
- **입력 전 자문**: "이 내용이 내일 뉴스에 나가도 괜찮은가?" → No면 입력하지 않기
- **민감정보는 익명화**: 고객명 → "고객 A", 매출 → "약 XX억 수준"
- **AI 결과물은 사람이 검증** 후 활용
- 사고 의심·문의 → **#gc-ai-라운지**
- 전문: `00-system/03-guides/AI-보안-가이드.md`

## 주의사항

- **하나씩 질문**: 한 번에 여러 질문하지 않기
- **간단하게**: 복잡한 설명 없이 핵심만
- **덮어쓰기 확인**: 기존 파일이 있으면 반드시 확인
- **경로 정확히**: CLAUDE.md는 워크스페이스 루트에 생성
- **보안 섹션 필수**: 생성하는 CLAUDE.md에 보안 원칙을 반드시 포함
