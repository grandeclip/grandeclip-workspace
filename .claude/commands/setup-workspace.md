# 워크스페이스 초기 설정

## 기본: 수업용 설정

사용자가 `--work` 또는 회사 업무용 전체 설정을 명시하지 않았다면 이 절만 수행하고 끝냅니다.

1. `README.md`의 **AI 초기 설정 절차**를 읽습니다.
2. 현재 Claude Code 환경과 OS에 맞는 `--workshop --tool claude` 또는 `-Workshop -Tool Claude` 명령으로 포함된 스킬을 확인합니다. 실행 결과가 실패하면 실제 경로와 필요한 조치만 안내합니다.
3. 파일 준비 뒤에는 같은 폴더의 새 대화에서 `career-os`, `karpathy-llm-wiki`, `skill-creator`의 실제 인식을 확인하도록 안내합니다.
4. 스킬 파일 준비와 위키 실행 환경을 구분합니다. Node.js 20 이상이 없으면 `README.md`의 공식 설치 안내를 보여주며 위키 실행 준비가 끝났다고 말하지 않습니다. 위키를 열어달라는 요청을 받은 경우에만 **내 위키 열기** 절차로 로컬 서버를 실행하고 실제 CLI·로그인 상태를 확인합니다.

수업용 설정에서는 아래 업무용 흐름, 외부 플러그인 설치, 개인 프로필·Daily Note 생성, 전역 적용을 실행하지 않습니다. 이름·직무를 질문하지 않고 기존 파일과 설정을 보존합니다.

## 선택: 회사 업무용 전체 설정 (`--work`)

이하 절차는 `--work` 또는 회사 업무용 전체 설정을 명시한 경우에만 실행합니다. 먼저 OS에 맞는 읽기 전용 진단을 실행하고 출력을 Step 0의 입력으로 사용합니다.

- macOS/Linux: `bash install.sh --check`
- Windows: `powershell -NoProfile -ExecutionPolicy Bypass -File install.ps1 -Check`

Bash를 미리 실행하는 동적 진단 블록은 사용하지 않습니다. Windows에서는 처음부터 PowerShell을 사용합니다.

### Step 0: 위 진단 결과 처리 (조용히, 필요할 때만)

- `.claude/skills/career-os/skills/company-research/SKILL.md`
- `.claude/skills/career-os/skills/job-scout/SKILL.md`

- `.claude/skills/career-os/agents/experience.md`
- `.claude/skills/career-os/agents/writing.md`
- `.claude/skills/career-os/references/runtime-contract.md`

모두 읽을 수 있을 때만 career-os 준비 완료로 기록하세요. 정상일 때는 별도 설명 없이 진행합니다.
누락되거나 읽을 수 없는 파일이 있으면 해당 경로를 알려주고, `.claude` 폴더를 포함한 워크스페이스를 다시 받아 달라고 안내하세요.
이 경우 career-os가 준비됐다고 말하지 않고, 아래 플러그인 확인과 개인 설정은 계속 진행합니다.

이어서 위 플러그인 진단 블록을 읽고 아래 세 갈래 중 하나를 고르세요. 사용자에게는 **문제가 있을 때만** 보입니다.

#### (A) "스킬 N 개가 모두 설치되었습니다" 인 경우 — 정상

**아무 말 없이 Step 1 로 넘어가세요.** 진단했다는 사실조차 언급하지 마세요.

#### (B) "설치됨 N 개 · 누락 M 개" 인 경우

**묻지 말고 바로 설치하세요.** 사용자는 이미 `/setup-workspace --work` 로 설정을 요청했고,
README 도 "이것만 입력하면 끝"이라고 안내합니다. 여기서 [예/아니오]를 물으면
"아니오"를 고른 사람이 반쪽짜리 워크스페이스를 갖게 되는데, 그게 바로 이 단계가
막으려는 문제입니다.

시작한다는 사실과 걸리는 시간만 알립니다:

```
설정을 시작하기 전에, 필요한 스킬 몇 개를 먼저 받아올게요.
몇 분 걸리고 네트워크 연결이 필요해요. 잠시만요 🙂
```

그리고 OS 에 맞는 설치 명령을 실행합니다:
- macOS/Linux → `bash install.sh --yes`
- Windows → `powershell -ExecutionPolicy Bypass -File install.ps1 -Yes`

**끝나면 반드시 OS에 맞춰 다시 진단하세요** (macOS/Linux: `bash install.sh --check`, Windows: `powershell -NoProfile -ExecutionPolicy Bypass -File install.ps1 -Check`).
스크립트는 개별 명령의 성공 여부를 믿지 않고 실제 설치 상태로 판정하도록 만들어져 있습니다.

- **모두 설치됨** → "다 받았어요!" 정도로 짧게 알리고 Step 1 로.
- **여전히 누락** → 설치를 **한 번만 더** 시도합니다(네트워크 일시 오류가 흔합니다).
  그래도 남으면 아래처럼 알리고 **설정은 계속 진행합니다**:

  ```
  스킬 몇 개를 못 받았어요:
  {누락된 항목을 이름 그대로 나열}

  설정은 계속 진행할게요. 나중에 /setup-workspace --work 를 다시 실행하면 이어서 받아옵니다.
  계속 안 되면 위 목록을 그대로 #gc-ai-라운지 에 올려주세요.
  ```

#### (C) 진단 자체가 실패한 경우

블록에 `No such file`, `command not found`, 빈 출력 등이 보인다면:

- **`install.sh` 를 못 찾음** → 폴더 복사가 덜 된 것입니다(`.claude` 같은 점으로 시작하는
  폴더가 빠지는 사고가 흔합니다). 그 사실을 알리고 공유받은 폴더를 다시 받으시라고
  안내한 뒤 **여기서 멈춥니다**. 계속하면 반쪽짜리가 됩니다.
- **`bash` 를 못 찾음(윈도우)** → `powershell -ExecutionPolicy Bypass -File install.ps1 -Check`
  를 직접 실행해 결과를 얻은 뒤, 그 결과로 (A)/(B) 를 판단하세요.

### Step 6: 전역 적용 (선택)

완료 안내 후, 아래 문구로 **딱 한 번** 물어봅니다:

```
마지막으로 — 방금 만든 설정(편리한 커맨드 + 회사 보안 지침)을
이 컴퓨터 어디서든 쓸 수 있게 해드릴까요? 추천해요 🙂  [예 / 아니오]
```

**"예"인 경우:**
1. OS를 감지한다.
   - macOS/Linux → `bash 00-system/02-scripts/globalize.sh` 실행
   - Windows → `powershell -ExecutionPolicy Bypass -File 00-system/02-scripts/globalize.ps1` 실행
2. 스크립트의 요약 출력(링크/복사·유지·충돌 수)을 확인하고, 사용자에게는 **친근한 한국어로** 전달한다. 예:
   ```
   ✅ 커맨드와 회사 보안 지침을 이 컴퓨터 전체에 적용했어요.
   이제 어느 폴더에서 Claude를 열어도 그대로 동작합니다.
   ```
3. 충돌이 보고되면, 덮지 않았음을 알리고 항목명을 그대로 전달한다.

**"아니오"인 경우:**
```
알겠어요! 이 설정은 지금 워크스페이스 폴더 안에서만 동작합니다.
나중에 /setup-workspace --work를 다시 실행하면 언제든 전역 적용할 수 있어요.
```

**주의:**
- 이 단계는 사용자의 개인 컴퓨터 전역 설정(`~/.claude`)을 바꿉니다. 반드시 동의를 받은 뒤에만 스크립트를 실행하세요.
- Windows 복사 방식은 repo가 업데이트되면 재실행이 필요함을 함께 안내하세요.
- **install 스크립트와 역할이 다릅니다.** `install.sh`/`install.ps1` 은 마켓플레이스 **플러그인**을
  사용자 전역(`--scope user`)으로 설치하므로 이미 어느 폴더에서든 동작합니다.
  이 Step 6은 그와 별개로 **이 워크스페이스 고유의** 커맨드·에이전트·스킬(`.claude/` 안의 것)과
  회사 보안 지침을 전역에 연결합니다. 둘은 겹치지 않습니다.

- **하나씩 질문**: 한 번에 여러 질문하지 않기
- **간단하게**: 복잡한 설명 없이 핵심만
- **덮어쓰기 확인**: 기존 파일이 있으면 반드시 확인
- **경로 정확히**: CLAUDE.md는 워크스페이스 루트에 생성
- **보안 섹션 필수**: 생성하는 CLAUDE.md에 보안 원칙을 반드시 포함
