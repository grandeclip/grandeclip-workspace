# Setup Workspace - 초기 설정 마법사

grandeclip 워크스페이스를 처음 사용할 때 실행하는 대화형 설정 도구입니다.
**개인 CLAUDE.md를 자동으로 생성**하여 Claude가 여러분의 업무 맥락을 이해할 수 있게 합니다.

---

## 실행 흐름

### Step 1: 환영 및 안내

먼저 **아래 클립 아트와 슬로건을 코드블록(```)으로 감싸 그대로 출력**하세요. 정렬이 깨지지 않게 monospace로 보여야 합니다. 이어서 환영 메시지를 출력합니다.

클립 아트 (그대로 출력):

```

---

### Step 2: 사용자 정보 수집 (대화형)

**순서대로 하나씩 질문하세요:**

#### Q1. 이름
```
이름이 어떻게 되세요?
```

#### Q2. 팀/직무
```
어떤 팀에서 어떤 일을 하고 계세요? (예: 마케팅, 세일즈, PM, 디자인, 개발, 운영 등)
```

#### Q3. 주요 관심사
```
주로 어떤 업무·분야에 관심이 있으세요? (예: 콘텐츠, 데이터 분석, 기획, 자동화 등)
```

#### Q4. 워크스페이스 용도
```
이 워크스페이스를 어떤 용도로 사용하실 건가요?
(예: 개인 업무 관리, 프로젝트 문서화, 학습 기록, 아이디어 정리 등)
```

---

### Step 3: CLAUDE.md 자동 생성

수집한 정보로 워크스페이스 루트의 `CLAUDE.md` 파일을 생성합니다.

**생성할 CLAUDE.md 템플릿:**

```markdown
# CLAUDE.md

## 사용자 프로필

**이름**: {이름}
**팀/직무**: {팀/직무}
**주요 관심사**: {주요 관심사}

## 워크스페이스 목적

{워크스페이스 용도}

## 폴더 구조 (Johnny Decimal)

\```
00-inbox/       - 빠른 캡처 (임시 보관)
00-system/      - 시스템 설정, 템플릿, 가이드
10-projects/    - 활성 프로젝트 (시한부)
20-operations/  - 지속적 운영 업무
30-knowledge/   - 지식 아카이브
40-personal/    - Daily Note, Todos
50-resources/   - 참고 자료
90-archive/     - 완료된 프로젝트
\```

## 주요 커맨드

| 커맨드 | 용도 |
|--------|------|
| `/daily-note` | 오늘 Daily Note 생성 |
| `/thinking-partner` | 생각 정리 파트너 |
| `/todo`, `/todos` | 할 일 관리 |
| `/idea` | 아이디어 추출·저장 |

## 작업 규칙

- 파일 수정 시 기존 파일 편집 우선 (새 파일 생성 최소화)
- Johnny Decimal 네이밍: `[숫자]-[설명적-이름]`

## 현재 진행 중인 프로젝트

(프로젝트가 생기면 여기에 추가)

---

*CLAUDE.md는 Claude가 업무 맥락을 이해하는 핵심 파일입니다.*
*자세한 가이드: `00-system/03-guides/CLAUDE-MD-BEST-PRACTICES.md`*
```

**중요**:
- 파일 경로는 실제 워크스페이스 루트에 생성
- 기존 CLAUDE.md가 있으면 덮어쓸지 확인
- **보안 원칙 섹션은 반드시 포함**할 것 (회사 정책)
- **보안 섹션은 반드시 `00-system/03-guides/global-security-block.md`의 내용을 그대로 사용**할 것(회사 정책 단일 원천). 임의로 문구를 바꾸지 말 것.

### Step 4: 필수 폴더/파일 생성

### Step 6: 전역 적용 (선택)

완료 안내 후, 아래 문구로 **딱 한 번** 물어봅니다:

```
마지막으로 — 방금 만든 설정(편리한 커맨드 + 회사 보안 지침)을
이 컴퓨터 어디서든 쓸 수 있게 해드릴까요? 추천해요 🙂  [예 / 아니오]
```

**"예"인 경우:**
1. OS를 감지한다.
   - macOS/Linux → `bash 00-system/02-scripts/globalize.sh` 실행
   - Windows → `powershell -ExecutionPolicy Bypass -File 00-system/02-scripts/globalize.ps1` 실행
2. 스크립트의 요약 출력(링크/복사·유지·충돌 수)을 확인하고, 사용자에게는 **친근한 한국어로** 전달한다. 예:
   ```
   ✅ 커맨드와 회사 보안 지침을 이 컴퓨터 전체에 적용했어요.
   이제 어느 폴더에서 Claude를 열어도 그대로 동작합니다.
   ```
3. 충돌이 보고되면, 덮지 않았음을 알리고 항목명을 그대로 전달한다.

**"아니오"인 경우:**
```
알겠어요! 이 설정은 지금 워크스페이스 폴더 안에서만 동작합니다.
나중에 /setup-workspace를 다시 실행하면 언제든 전역 적용할 수 있어요.
```

**주의:**
- 이 단계는 사용자의 개인 컴퓨터 전역 설정(`~/.claude`)을 바꿉니다. 반드시 동의를 받은 뒤에만 스크립트를 실행하세요.
- Windows 복사 방식은 repo가 업데이트되면 재실행이 필요함을 함께 안내하세요.

---

## 주의사항

- **하나씩 질문**: 한 번에 여러 질문하지 않기
- **간단하게**: 복잡한 설명 없이 핵심만
- **덮어쓰기 확인**: 기존 파일이 있으면 반드시 확인
- **경로 정확히**: CLAUDE.md는 워크스페이스 루트에 생성
- **보안 섹션 필수**: 생성하는 CLAUDE.md에 보안 원칙을 반드시 포함

---

## 재실행

언제든 `/setup-workspace`로 다시 실행 가능합니다.
기존 CLAUDE.md가 있으면 덮어쓸지 물어봅니다.
