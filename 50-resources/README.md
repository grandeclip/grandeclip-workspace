# 50 Resources

참고 자료와 리소스를 저장하는 공간입니다.

## 용도

- 업무에 참고하는 외부 자료 (PDF, 이미지, 데이터 파일 등)
- 분석·실습에 사용할 데이터 파일

## 특징

- **외부 자료**: 본인이 작성하지 않은 외부 자료
- **참고용**: 필요할 때 참고하는 자료
- **정리된 형태**: 쉽게 찾을 수 있도록 카테고리별 정리
